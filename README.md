# Boosted USA

Учебный проект — вёрстка сайта Boosted USA по макету из Figma йоу.
https://www.figma.com/design/eUhQTRceLilzTDPtKmiiy9/BOOSTEDusa?node-id=1-1668&t=vhZ12WqD7liLpWQd-0

## 🛠 Технологии
- HTML
- CSS
- Google Fonts (Roboto)

## 📁 Структура проекта
- `index.html` — разметка сайта
- `css/style.css` — стили
- `img/` — изображения и иконки

## 🚀 Запуск
Открыть `index.html` в браузере или запустить через Live Server в VS Code.
